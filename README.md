# Nova Studio

Streaming software for the blind and visually impaired — a full streaming workstation that talks.

Nova Studio is built by CodeStark, accessibility-first from the ground up: go live, follow and send chat, discover streams and raid out, manage panels, overlays, clips, and a soundboard — everything spoken, everything keyboard-driven, no sighted help required.

## Download

Grab the latest Mac build from the [Releases](https://github.com/starkiller110/nova-studio/releases) page.

**Requirements:** Apple Silicon Mac.

**First launch:** Nova Studio isn't notarized by Apple yet, so macOS Gatekeeper will warn you the first time. Right-click the app, choose Open, and confirm. That's the standard path for independent Mac software outside the App Store.

## What's inside

- Go live and manage your stream without leaving the app
- Chat that reads to you, with discovery and raids built in
- Goldfish: describe a feature in plain words and Studio builds it into the app
- Forge: Studio can build, repair, and update itself
- Overlays, panels, a soundboard, clips, and more — every surface designed to be heard, not just seen

## Price

Nova Studio is free. An optional hosted version (we run the always-on server for you) and a supporter tier are in the works — they exist to cover server costs, never to lock the software itself away.
